20
Troubleshooting

Common issues and how to fix them.

❌ Device WiFi won't show up in my phone

Make sure the device is plugged in and the TFT shows "AP Ready". If it shows "WiFi Connected" instead, the device may have auto-connected to a saved network. Press the device reset button or clear WiFi via the admin portal at 192.168.4.1.

❌ "Fingerprint Not Recognized" during attendance

The student's finger may not be registered, or their fingerprint has changed (dirty/wet finger). Make sure the finger is clean and dry. If persistent, re-register the student from "Register User".

❌ "Already Registered" during fingerprint enrollment

This fingerprint is already assigned to another student. You must first delete that student's credentials from the "Users" page before re-enrolling them.

❌ "Fingerprint Mismatch" during enrollment

The student used different fingers for the 3 scans. All 3 scans must be the same finger. Start the registration over and use the same finger each time.

❌ "RFID Mismatch" during attendance

The fingerprint and RFID card don't belong to the same student. The device matched the fingerprint to Student A, but the RFID card belongs to Student B. This is a security check — both must match.

❌ Dashboard shows "DB:OFF" (Database Offline)

The device cannot reach the online database server. Check: (1) Is the device connected to WiFi? Go to WiFi Settings. (2) Is the server running? (3) Try clicking "Scan Networks" and reconnecting.

❌ "Try Again in Xm Ys" error during attendance

The student is trying to clock OUT too soon after clocking IN. They must wait for the configured delay period (check Attendance Rules). For example, if set to 15 minutes, they must wait 15 minutes before OUT is accepted.

❌ Device shows "Offline Mode" on the TFT screen

WiFi is not connected. The device still works in AP mode — you can access the admin portal, register students, and take attendance (saved locally). Once WiFi is restored, unsent attendance records will auto-sync to the online database.

❌ Can't access 192.168.4.1

Make sure you're connected to the FRANCIS_KEY WiFi network. Do not use a VPN. Try opening a new browser tab. If using a computer, make sure you're not also connected to another WiFi network simultaneously.

❌ "ID Card Already Registered" during RFID enrollment

This RFID card is already assigned to another student. Delete that student's credentials from "Users" first, then re-register the card to the new student.
