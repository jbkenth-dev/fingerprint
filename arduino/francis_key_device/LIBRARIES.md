# Required Arduino Libraries

Install these from Arduino IDE Library Manager:

| Library | Author |
|---|---|
| ArduinoJson | Benoit Blanchon |
| Adafruit Fingerprint Sensor Library | Adafruit |
| Adafruit PN532 | Adafruit |
| Adafruit GFX Library | Adafruit |
| Adafruit ILI9341 | Adafruit |
| RTClib | Adafruit |
| Adafruit BusIO | Adafruit |

These come from the ESP32 Arduino core:

```text
WiFi
WebServer
DNSServer
HTTPClient
Preferences
Wire
SPI
SD
FS
time
```

Recommended board package:

```text
esp32 by Espressif Systems
```
